# Food Estimation Skill

用于 AI 健身 / 饮食 App 的食物识别、份量估算、营养计算与不确定性管理规范。

核心原则：AI 负责识别、解释和估计；确定性程序负责营养计算。营养数据应可追溯，信息不足时展示估算区间，并只追问最有价值的问题。

## 当前状态

完整的 86 节规范已发布，见 [SKILL.md](SKILL.md)。本项目是开发规范，不是已实现的营养计算引擎，不保证照片估算精度。

## 使用说明

使用步骤：

1. 将其复制到应用项目的 `skills/food-estimation/SKILL.md`，或直接提供给开发 Agent。
2. 要求 Agent 阅读规范，对照现有代码实施食物标准化、份量证据处理、营养数据库查询和程序计算。
3. 以真实称重和营养标签验证误差及区间覆盖率，不把模型估计当作实测事实。

需自行接入有合法使用授权的营养数据库和模型服务。示例数值不应直接作为生产数据库；本规范不替代专业医疗或营养建议。
